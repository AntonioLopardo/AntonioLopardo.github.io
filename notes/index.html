  1. Multi-token prediction (MTP)

    A normal LM head predicts token t+1 from the hidden state at t. An MTP head is a small extra block — in DeepSeek-V3's version a single lightweight transformer layer per extra step — that takes the same hidden state plus the embedding of token t+1 and predicts t+2. It has its own cross-entropy loss, added to the main loss with a weight (Nemotron 3 Super uses 0.3). The backbone is shared; only the head is extra.

    Two reasons it survives into 2026 models: the training signal is denser and slightly forward-looking, and at inference the head is a draft model that lives inside the main model — it proposes t+2 cheaply, the main model verifies in one batched pass, and accepted tokens cost nothing. DeepSeek-V3 reports an acceptance rate above 80% for the first MTP head and roughly 1.8× decoding throughput. That is why Nemotron, Kimi K3, DeepSeek V4 and Gemma 4 all ship one.

    Two consequences show up in the post-training reports. RL moves the backbone and the draft's acceptance rate collapses, so Nemotron ends with an MTP healing stage that retrains only the heads. Kimi K3 goes further and fine-tunes its MTP layer into an EAGLE-3-style draft with a loss that maximizes acceptance rate directly instead of a KL surrogate. The metric that matters for a draft is acceptance rate, not accuracy.
